## 固定实验配置

训练种子为 0、1、2；每种算法请求 40000 步；评估种子为 20000–20019，每个训练种子在 20 个独立初始条件上评估。另用训练种子 3、4、5 与评估种子 10000–10019 作开发验证；最终测试之前固定算法配置。

```bash
python -m rl_learning verify --include-deep --algorithms ppo dqn a2c reinforce --seeds 0 1 2 --timesteps 40000 --eval-seed-base 20000 --output results/release
```

## 温控性能

| 算法 | 未训练 MAE °C | 训练后 MAE °C | 跨训练种子标准差 °C | 边界违规次数 |
| --- | --- | --- | --- | --- |
| PPO | 5.5248 | 0.1373 | 0.0152 | 0 |
| DQN | 4.3522 | 0.1473 | 0.0156 | 0 |
| A2C | 5.5248 | 0.1819 | 0.0047 | 0 |
| REINFORCE | 6.1464 | 0.2423 | 0.0615 | 0 |

相同评估初始条件下，随机控制 MAE 为 **3.1756°C**，规则控制为 **0.1230°C**。这四种训练策略都明显改善了未训练控制，但规则控制在这个简单、确定性的环境中仍更精确。此结果支持训练流程有效，不能支持“RL 一定优于规则控制”的结论。

## 基础实验

价值迭代与策略迭代符合解析最短路径价值；MC/TD 在随机游走上达到预定误差阈值；SARSA/Q-learning 和 Dyna-Q 学到 6 步最短路径；Bandit 的探索策略形成最优动作偏好。规划与计数奖励的实验保留原始学习曲线，不预设它们在所有情形都更好。

## 如何解读

32 个检查覆盖 6 个基础实验与 4 个神经网络温控算法。65 项回归测试检查环境与更新逻辑。它们不代表 12 课每一种算法均已完整实现。L9 不确定性、TRPO、MCTS、RND/NGU 及 HVAC/TEP 的性能验证仍需扩展，详见 [学习路径](learning_path.md)。

标准差反映训练种子之间的波动，不是置信区间。不同系统、库版本和硬件可能产生不同数值。首次短预算实验曾出现性能 FAIL，因此保留自动失败判定，固定预算并记录全部种子比单次展示更有解释力。

复现命令输出 `report.json`、`report.md`、`learning_curves.csv`、`evaluation.csv` 和各训练种子的检查点。原始输出保留在本地 `results/release/`，不把生成模型提交到仓库。
